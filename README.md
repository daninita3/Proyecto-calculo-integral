# Proyecto Cálculo Integral (Sólidos a revolución)
El proyecto a continuación trata del desarrollo de una página web en la cual se podrán visualizar y resolver sólidos a revolución basados (método de discos, arandelas y cascarones)

La primera versión de este proyecto se desarrolló en Visual Studio Code con ayuda de las librerías numpy, sympy y matplotlib las cuales permiten realizar cálculos numéricos rápidos, resolver operaciones matemáticas simbólicas (parecido a la función eval) y graficar los resultados de manera visual.

Primera versión en [solidosV1.py](solidosV1.py).
